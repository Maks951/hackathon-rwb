## Как продолжить

В чистой рабочей копии:

```powershell
git fetch origin
git switch --track origin/integration/qwen-runner
```

Если локальная ветка уже существует, переключиться на неё и выполнить
`git pull --ff-only origin integration/qwen-runner`; при расхождении истории
сначала сохранить и изучить локальные коммиты. Не использовать force/reset.

До восстановления доступа к Qwen можно собрать среду runner из корня репозитория:

```powershell
docker build -f infra/runner/Dockerfile.sandbox -t localhost/rwb-sandbox:dev .
```

После восстановления SSH-доступа запустить общий сценарий:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-stack.ps1
```

Он покажет команду туннеля для отдельного окна. Продолжать после установления
туннеля. Скрипт обновляет локальный `platform/.env`, собирает sandbox,
проверяет PostgreSQL и Qwen, запускает worker/runner и настоящую генерацию.
При первой ошибке останавливается. Не публиковать `.env` и секретные логи.
